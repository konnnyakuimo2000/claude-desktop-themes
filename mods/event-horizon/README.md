# Event Horizon

Claude デスクトップアプリ（Code タブ）の背景に、巨大なブラックホールとその降着円盤を描くダークテーマです。絵はすべて丸いドット（網点）でできていて、明るいところほどドットが大きくなります。

- 黒い影のまわりを細く明るい光子リングが囲み、重力で曲げられた円盤の奥側の光が、影の上下に弧を描きます
- 手前側の円盤が影の前を横切ります。こちらに向かってくる左側ほど明るく光ります
- 円盤の中の明るいかたまりが、内側ほど速く回ります（1.4秒ごとに1コマ、16コマで一巡）
- 遠くの星がまたたきます（数千のドットでできた本体は、アプリに止められないよう動かしていません）
- 配色（漆黒と琥珀色）と吹き出しの見た目もこのテーマで設定します

## テーマの切り替え

同じコレクションのテーマ（`galaxy-night`、`digital-rain`、`event-horizon`）を入れている場合は、Claude Code のプロンプトでテーマ名を入力すると切り替わります。

- `/event-horizon` … ブラックホールのテーマにする
- `/galaxy-night` … 銀河テーマにする
- `/digital-rain` … デジタルな雨テーマにする

今のセッションにすぐ反映され、選んだテーマは `~/.claude/claude-desktop-themes.json` に保存されるので、次のセッションからもそのテーマになります。

## 必要なもの

- Claude Code v2.1.323 以降と、mod の背景を描く Claude デスクトップアプリ
- OS の「アニメーション効果」がオン（オフだと止まった絵になります）

## ファイル

- `hooks/register.tsx` — 配色・吹き出し・背景の設定
- `hooks/scene.ts` — ドットの背景を組み立てるコード（ブラックホールの位置 `CX` / `CY`、大きさ `SHADOW`、円盤の傾き `TILT`、ドットの間隔 `GRID` はここ）
- `hooks/choice.ts` — どのテーマを使うかの保存と読み込み
- `hooks/make-colors.js` — 配色を作る補助（Claude Code のスキルからコピー）
- `tests/backdrop.test.tsx` — 背景が描けるかのテスト
